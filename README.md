# CampusDesk — Student Management Dashboard

A responsive front-end demo for managing student records, daily attendance, and course summaries.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser. For the best development experience, use VS Code with Live Server.

## Features
- Overview dashboard with student and attendance metrics
- Add, edit, search, filter, and delete student records
- Attendance register by date
- Course overview with live student counts
- CSV export for student, attendance, and course reports
- Browser `localStorage` persistence
- Responsive desktop and mobile layout

## Publish using GitHub Pages
1. Create a **public** repository named `campusdesk-student-management`.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Your site URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/campusdesk-student-management/`

## Important limitation
GitHub Pages hosts static files only. This version is a front-end demo; it does not run a Java backend or connect to a shared database. Records are stored in the current browser only, so they do not sync across devices. Do not enter real or sensitive student information.
